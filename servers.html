How to join

Connecting to a server

  1. Download and start Aldervast 1.14.41.
  2. On the main menu choose Join a Server.
  3. Type the server's address and port from the list above (for the Alpha Server, 85.190.113.87 and 24650).
  4. Choose an account name (3 to 20 letters, digits or underscores) and a password (at least 4 characters).
  5. The first time, tick Create this account if it doesn't exist, then Connect. After that leave it unticked and log in with the same name and password.
  6. Make a hero and step into the world. Everyone else on the server is there with you.

Good to know

  • Characters on a server are separate from your Single Player ones, and are kept by that server.
  • The connection is not encrypted, so use a password you do not use anywhere else.
  • Logging in to the same account from a second PC drops the first.
  • If the server has just restarted you may see "The server is busy" while everyone logs back in; the game tries again by itself.
